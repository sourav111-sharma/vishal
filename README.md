# Physics Made Easy – The Doppler Effect

An interactive, responsive educational website demonstrating the physics of the Doppler Effect. Built with HTML5 Canvas, Tailwind CSS, and vanilla JavaScript. 

## Features
- **Interactive Simulation:** A built-in HTML5 Canvas visualization showing sound wave propagation based on the sound source's speed.
- **Responsive UI:** Tailored layout for mobile, tablet, and desktop viewing.
- **Integrated Quizzes:** Mini knowledge checks to reinforce basic physics definitions.

## How to Host on GitHub Pages

1. **Create a new repository** on your GitHub account (e.g., `doppler-effect`).
2. **Upload these four files** directly to the main branch of your new repository:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
3. In your GitHub repository, go to **Settings** > **Pages**.
4. Under the **Build and deployment** section, select **Deploy from a branch**.
5. Set the branch to `main` (or `master`) and the folder to `/ (root)`. Click **Save**.
6. Wait 1–2 minutes. GitHub will provide you with a live URL where your website is hosted!
